# SSC CGL 2026 · Tier 1 · Complete Edition

A free, static study website for SSC CGL 2026 Tier 1 preparation.

## Contents
- `index.html` — home page linking all sections
- `quant.html` — Quantitative Aptitude (2060+ questions, 21 topics)
- `reasoning.html` — General Intelligence & Reasoning (1520 questions, 15 topics, 2-5 formats per topic)
- `english.html` — English Language (494 questions, 8 topics — vocabulary + grammar)
- `ga.html` — General Awareness (130 curated questions, 7 topics)

## How to publish on GitHub Pages
1. Create a new GitHub repository (e.g. `ssc-cgl-2026`).
2. Upload all 5 `.html` files (and this README) to the repo root.
3. Go to **Settings → Pages**, set source to the `main` branch, root folder.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Status / what's next
- Quant and Reasoning are feature-complete for this edition, each topic mixing several
  distinct question formats (not one repeated template).
- English covers 8 topics: Synonyms, Antonyms, One Word Substitution, Idioms, Spelling
  Correction, Spotting Errors (3 sub-types), Active/Passive Voice, Direct/Indirect Speech.
  Reading Comprehension and Cloze Test (which need full passages) are the natural next step.
- General Awareness intentionally ships with a smaller, accuracy-checked static-GK
  set across 7 topics (Polity, History, Geography, Science, Economy, Sports, Static GK).
  Current Affairs is left out on purpose — it needs a live, dated source, not a
  generated list.
