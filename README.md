# SSC CGL 2026 · Tier 1 · Complete Edition

A free, static study website for SSC CGL 2026 Tier 1 preparation.

## Contents
- `index.html` — home page linking all sections
- `quant.html` — Quantitative Aptitude (2060+ questions, 21 topics)
- `reasoning.html` — General Intelligence & Reasoning (1000 questions, 10 topics)
- `english.html` — English Language (240 curated questions, 5 topics)
- `ga.html` — General Awareness (75 curated static-GK questions, 5 topics)

## How to publish on GitHub Pages
1. Create a new GitHub repository (e.g. `ssc-cgl-2026`).
2. Upload all 5 `.html` files (and this README) to the repo root.
3. Go to **Settings → Pages**, set source to the `main` branch, root folder.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Status / what's next
- Quant and Reasoning are feature-complete for this edition.
- English currently covers Synonyms, Antonyms, One Word Substitution, Idioms, and
  Spotting Errors (Subject-Verb Agreement). Reading Comprehension and Cloze Test
  are natural next additions.
- General Awareness intentionally ships with a smaller, accuracy-checked static-GK
  set (Polity, History, Geography, Science, Static GK). Current Affairs is left out
  on purpose — it needs a live, dated source, not a generated list.
